## 设计约定

### 每个场景文档统一结构

1. **场景概述**：一句话描述、典型诉求、频次
2. **用户角色与权限**：谁发起、谁审批、谁查看
3. **意图与槽位定义**：意图标签、必填/选填槽位、槽位类型与约束
4. **业务流程**：端到端流程图（Mermaid）
5. **业务规则与校验**：规则清单、校验时机、错误码
6. **风险等级与授权策略**：全自动 / 自动留痕 / 人工确认
7. **工具调用设计**：调用哪些外部系统、入参出参、幂等/重试策略
8. **异常处理与兜底**：失败场景、转人工条件、用户提示
9. **审计要求**：必须记录的字段
10. **测试用例**：正常流程、边界条件、异常场景
