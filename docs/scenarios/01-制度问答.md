# REQ-01 制度问答

> 场景编号：REQ-01　|　意图标签：`policy_query`　|　频次：高　|　复杂度：简单　|　自动化：✅ 全自动

---

## 1. 场景概述

**一句话描述**：员工用自然语言提问公司制度/流程/FAQ，系统从知识库检索相关文档并生成回答，附引用来源。

**典型诉求**：
- "年假有几天"
- "报销打车上限多少"
- "会议室怎么预定"
- "请假流程是什么"
- "差旅标准是什么"

**用户价值**：替代行政人员反复回答同类问题，统一制度口径，7×24 小时可用。

---

## 2. 用户角色与权限

| 角色 | 操作 | 权限 |
|------|------|------|
| 普通员工 | 发起查询 | 可查看 L1（公开）/ L2（内部）级制度文档 |
| 部门主管 | 发起查询 | 同上 |
| 行政专员 | 维护知识库 | 上传/编辑/删除文档 |
| 系统管理员 | 管理知识库 | 全部操作 |

**权限校验**：查询时按用户角色过滤可见文档范围（L1/L2 全员可见，L3/L4 需额外权限）。

---

## 3. 意图与槽位定义

### 3.1 意图识别

| 字段 | 值 |
|------|-----|
| 意图标签 | `policy_query` |
| 业务类型 | 无（不创建任务） |
| 触发关键词 | 制度、规定、标准、流程、怎么、几天、多少、上限、规则 |
| LLM Prompt | 见 `app/admin_ai/core/agent/prompt.py` INTENT_PROMPT |

### 3.2 槽位定义

制度问答**无必填槽位**，用户提问即为查询条件。

| 槽位 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | 是 | 用户原始问题，直接作为 RAG 检索 query |
| `category` | string | 否 | 知识分类过滤（制度/流程/FAQ），由意图推断 |

---

## 4. 业务流程

```mermaid
flowchart TD
    A[用户提问] --> B[意图识别 = policy_query]
    B --> C[RAG 检索知识库]
    C --> D{是否有命中结果?}
    D -- 有 --> E[LLM 生成回答 + 附引用来源]
    D -- 无 --> F[回复"未找到相关制度，建议联系行政"]
    E --> G[返回回答给用户]
    F --> G
    G --> H[记录对话 + 审计日志]
```

**流程说明**：

1. 用户输入自然语言问题
2. 意图识别为 `policy_query`
3. 将用户原始问题作为 query 送入 RAG 检索
4. 检索命中 → LLM 基于检索结果生成回答，附引用来源（文档标题 + 段落）
5. 检索未命中 → 返回兜底话术，建议联系行政专员
6. 全程记录审计日志

---

## 5. 业务规则与校验

| 规则 | 说明 | 校验时机 |
|------|------|----------|
| R-01 | 回答必须基于检索结果，禁止 LLM 编造 | LLM 生成时 |
| R-02 | 回答必须附引用来源（至少 1 条） | 响应组装时 |
| R-03 | 检索结果为空时，不得生成"据我所知"类回答 | 检索后判断 |
| R-04 | L4 级文档需额外权限才能检索 | RAG 检索前 |
| R-05 | 高频问题可缓存，TTL 1 小时 | 缓存层 |

**Prompt 约束**（注入 system prompt）：
```
你是一个企业行政助手。请仅基于以下检索结果回答用户问题。
如果检索结果中没有相关信息，请明确说"未找到相关制度"。
禁止编造或推测。每个要点必须标注引用来源。
```

## 7. 工具调用设计

制度问答**不调用外部业务系统**，仅使用内部 RAG 检索。

### 7.1 RAG 检索调用

| 字段 | 值 |
|------|-----|
| 工具名 | `rag_retriever` |
| 入参 | `query: str, top_k: int = 5, filters: Optional[dict]` |
| 出参 | `list[dict]` — 每项含 `content`, `metadata`, `distance` |
| 超时 | 5s |
| 重试 | 1 次 |
| 降级 | 检索失败时返回"系统繁忙，请稍后重试" |

### 7.2 缓存策略

| 缓存对象 | Key | TTL | 失效方式 |
|----------|-----|-----|----------|
| 查询结果 | `qa:{sha256(query)}` | 1 小时 | 知识库更新时按前缀清理 |

---

## 8. 异常处理与兜底

| 异常场景 | 处理方式 | 用户提示 |
|----------|----------|----------|
| RAG 检索超时 | 重试 1 次，仍失败则降级 | "系统繁忙，请稍后重试" |
| RAG 检索无结果 | 返回兜底话术 | "未找到相关制度，建议联系行政专员" |
| LLM 生成超时 | 返回检索结果摘要 | "以下是相关文档摘要，请参考" |
| LLM 生成内容无引用 | 拦截，要求重新生成 | 不展示给用户 |
| 知识库不可用 | 降级为"无知识引用"回答 | "知识库暂时不可用，回答可能不够准确" |

**转人工条件**：用户连续 3 次表示"没回答到点上"或主动要求转人工。
