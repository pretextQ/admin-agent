# 当前状态

更新：2026-10-06。代码核对基线：`163e4d7`；本轮只整理文档，不修复下列代码问题。

## 1. 项目处于什么阶段

Admin AI Agent 是企业行政智能助理原型，版本 `0.1.0` / Alpha。后端 FastAPI + SQLAlchemy，员工端 React 19 + TypeScript。已具备对话、规则、工具转发、任务落库及本地审批流程；OA、财务、物资联调对象仍是开发桩，不代表真实企业系统已经接入。

现有代码识别 13 类意图，其中 9 类映射到可办理的业务类型，另有制度问答、状态查询、问候与其他。产品设计包含 11 个场景；车辆预定尚未独立路由，不能将场景数、意图数和工具注册数混为同一个完成度指标。

## 2. 已实现与主要限制

| 模块 | 已有实现 | 限制 |
|---|---|---|
| 对话 | 多轮补槽、会话属主检查、确认卡片、历史落库 | 并发确认缺少原子消费机制；完成后状态残留需核查 |
| 模型 | 意图、槽位、回复经 LLMGateway；失败回退 | 单供应商；脱敏策略不等于完整的数据合规验收 |
| 工具 | HTTP 转发与下游受理编号提取 | 开发桩联调；真实鉴权、参数契约、幂等与重试需适配 |
| 审批 | 部门/金额/槽位条件路由、委派、任一人/会签、加签 | 工具调用早于本地建审批链；审批通过/拒绝/取消未与真实下游闭环 |
| 组织 | HR HTTP / CSV 同步、SQL 归属过滤 | 使用演示组织；主管、HR/法务角色需真实数据维护 |
| 规则 | 日期、金额、数量及场景基础校验 | 假期余额示例值；负数报销可通过；warnings 未被流程完整消费 |
| 知识库 | 文本切片、Chroma 检索/写入、管理接口关键词回退 | 嵌入模型未显式接入；问答用模板摘录；无命中时可能返回未消费的 needs_rag 标记 |
| 状态查询 | 本人单据进度与 HR 假期余额 | HR 是开发桩；对话跨用户查询尚未实现 |
| 认证 | 飞书 OAuth、本地 JWT、开发登录 | Redis 故障会跳过 OAuth state 校验；停用账号与角色变更生效需核查 |
| 审计 | 写操作落 audit_logs、请求 TraceId | 请求体未统一脱敏；失败不阻断业务；尚无哈希链/WORM 保证 |
| 员工端 | 登录、聊天、确认、任务、审批、历史恢复 | 无现成前端测试用例；加签与后台界面未接入 |

代码入口：`app/admin_ai/main.py` → `api/chat.py` → `core/agent/orchestrator.py`。审批在 `core/approval/`，查询在 `core/status_query.py`，模型边界在 `core/llm_gateway.py`，前端在 `frontend/src/`。

- WebSocket：已注册回显端点，未鉴权、未接编排器；前端使用 HTTP。
- 管理后台 UI：只有设计，部分管理 API 已存在。
- 限流：有配置与错误码，未接中间件。
- Prometheus、告警、性能压测：未落地；`/admin/metrics` 部分值为占位值。
- Dockerfile、Compose、nginx 配置、CI 与 pre-commit 配置：仓库未提供可直接使用的文件。
- `services/chat_service.py`、`task_service.py`、`knowledge_service.py` 中的骨架不能作为主流程已完成的证据；当前主流程在 API 层。
