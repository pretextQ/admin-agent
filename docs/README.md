## 开始开发

按顺序阅读以下三份文档即可开始，不需要先通读历史评审。

1. [开发入门](guides/开发入门.md)：在 `D:\projects\admin-ai-agent` 准备环境、启动服务。
2. [当前状态](guides/当前状态.md)：已有实现、验证范围和已知缺口。
3. [开发计划](planning/开发计划.md)：下一步任务、优先级和验收标准。

## 文档维护规则

- 实现情况只维护在「当前状态」，未完成任务只维护在「开发计划」，验证结果附日期、命令与范围。
- 产品、场景与架构文档描述目标设计；设计写了某项能力，不代表代码已经具备。
- API 变更同时更新接口文档与调用方。文件移动时修正相对链接，代码路径从仓库根目录理解。
- 一项任务完成时更新状态和验收证据，再提交代码；不要追加另一份交接报告或重复待办表。
- 历史归档不再维护进度。原提交哈希与旧机器路径仅用于追溯，不作为当前环境配置。
